# 🎮 Battle of Sea - Запуск игры

## Вариант 1: Быстрый запуск (все в одной команде)

```bash
# Откройте 3 терминала и запустите:

# Терминал 1 - Сервер
cd /Users/masha/battle_of_sea/battle_of_sea/battle_of_sea && dotnet run

# Терминал 2 - Клиент 1  
cd /Users/masha/battle_of_sea/client && dotnet run --project BattleOfSea.csproj

# Терминал 3 - Клиент 2
cd /Users/masha/battle_of_sea/client && dotnet run --project BattleOfSea.csproj
```

## Вариант 2: Автоматический запуск

```bash
bash /Users/masha/battle_of_sea/start_game.sh
```

## Как играть

1. **Первый клиент:**
   - Окно откроется с лобби
   - Нажмите "Создать комнату" и введите имя комнаты (например "кк")
   - Нажмите "Создать"

2. **Второй клиент:**
   - Окно откроется с лобби
   - Вы должны увидеть комнату созданную первым клиентом
   - Нажмите на комнату и нажмите "Присоединиться"
   - Оба игрока должны быть подключены к одной комнате

3. **Игра:**
   - После присоединения второго игрока начнется игра
   - Вы можете расставить корабли и начать играть

## Логирование

Смотрите логи чтобы отследить что происходит:

```bash
# Логи сервера
tail -f /tmp/server.log

# Логи клиента 1
tail -f /tmp/client1.log  

# Логи клиента 2
tail -f /tmp/client2.log
```

## Порты

- Сервер WebSocket: **5555** (ws://localhost:5555)
- Убедитесь что порт 5555 не занят другим приложением

## Если не работает

1. **Сервер не запускается:**
   - Проверьте есть ли процесс на порту 5555: `lsof -i :5555`
   - Убейте старый процесс: `pkill -f "battle_of_sea"`

2. **Клиент не подключается:**
   - Проверьте что сервер запущен
   - Посмотрите логи клиента: `tail /tmp/client1.log`
   - Проверьте что порт 5555 свободен

3. **Второй клиент не видит комнату:**
   - Перезагрузите лобби (нажмите F5 или обновите список)
   - Посмотрите логи сервера в /tmp/server.log
