## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1️⃣: Найдите окна клиентов

Должны быть **ДВА** окна приложения "Battle of Sea" (Avalonia).

Если окна не видны:

- Если приложения не запустились, смотрите ниже "Чтобы запустить клиент вручную"

---

### Шаг 2️⃣: Первый клиент - создать комнату

**В ПЕРВОМ окне клиента:**

1. ✅ Вы должны видеть **экран лобби** с кнопкой "Создать комнату"
2. 🔘 Нажмите кнопку **"Создать комнату"**
3. 💬 Введите название: **`TestGameFlow`**
4. 🔒 Оставьте пароль пустым
5. ✅ Нажмите **"Создать"**

**Ожидаемо:**
- Экран изменится на игровой экран
- Вы должны увидеть две доски (ваша и противника)
- В статус-баре: `⏳ Ожидание соперника...`
- **ВАЖНО:** НЕ нажимайте "Готово" пока второй клиент не присоединится!

---

### Шаг 3️⃣: Второй клиент - присоединиться к комнате

**ВО ВТОРОМ окне клиента:**

1. ✅ Вы должны видеть **экран лобби** со списком комнат
2. 🔍 В списке комнат найдите **`TestGameFlow`**
   - Если комнаты не видны, нажмите кнопку обновления
3. 🖱️ Кликните на комнату **`TestGameFlow`**
4. ✅ Нажмите **"Присоединиться"** (или Enter)
5. 🔒 Если есть пароль, оставьте пустым

**Ожидаемо:**
- Экран изменится на игровой экран
- Вы должны увидеть две доски
- В статус-баре: `⏳ Ожидание соперника...`

---

### Шаг 4️⃣: Разместить корабли - ПЕРВЫЙ клиент

**В ПЕРВОМ окне:**

1. 🚢 Вы должны увидеть слева экран "Расстановка кораблей"
2. 📍 Выберите размер корабля (слева есть кнопки 1, 2, 3, 4)
3. 🖱️ Кликните на доске, где хотите разместить корабль
4. ↻ Если нужно повернуть, нажмите **"Повернуть"**
5. 🗑️ Если нужно удалить, выберите корабль и нажмите **"Удалить"**
6. ✅ Когда разместили все 10 кораблей, экран автоматически изменится на игровой

**Проверьте:**
- Внизу должны быть счетчики: "Ваши корабли: X" и "Корабли противника: 0"

---

### Шаг 5️⃣: Разместить корабли - ВТОРОЙ клиент

**ВО ВТОРОМ окне:**

Повторите ШАГ 4️⃣ - разместите свои 10 кораблей.

**Когда закончите:**
- Статус изменится на: `✅ Соперник найден! Можно играть`
- Должна появиться зеленая кнопка: **"✅ Готово"**

---

### Шаг 6️⃣: Нажать "Готово" - ОБА клиента

**В ОБОИХ окнах (когда появится кнопка "✅ Готово"):**

1. 🟢 Нажмите кнопку **"✅ Готово"** (Ready button)
2. ⏳ Ожидайте...

**Ожидаемо:**
- Кнопка "Готово" исчезнет
- Статус изменится на:
  - **Первый клиент:** `Ваш ход` (зеленый фон)
  - **Второй клиент:** `Ход соперника` (серый фон)

**Если этого не произойдет:**
- Проверьте логи (смотрите ниже)

## 🔍 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема: Кнопка "✅ Готово" не видна

**Диагностика:**
1. Откройте терминал
2. Выполните:
```bash
tail -100 /tmp/server.log | grep -A 5 -B 2 "GameStateChanged\|ReadyToStart"
```

**Ищите:**
- `[DEBUG][GameVM] OnGameStateChanged` - GameStateChanged получено?
- `[StateToReadyVisibleConverter] IsVisible=True` - конвертер вернул true?
- `[DEBUG] Current State after assignment: ReadyToStart` - State обновлен?

---

### Проблема: "Ожидание соперника" остается навсегда

**Это значит:**
- Второй клиент не присоединился
- Или корабли не разместились
- Или Ready не отправился на сервер

**Проверьте:**
```bash
tail -50 /tmp/server.log | grep "PlayerReady\|Players"
```

---

### Проблема: Вообще ничего не работает

**Сбросьте:**
1. Закройте оба клиента
2. В терминале:
```bash
pkill -9 -f dotnet
```
3. Запустите заново (смотрите ниже)
